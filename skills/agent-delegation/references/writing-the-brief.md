# Write the brief

A separate process usually lacks the current conversation. Give it the facts it needs to act
independently and identify the resources already available in its workspace or session. A direct
forward can be enough when the user's request is self-contained. When the user asks for a verbatim
handoff, keep launch details separate from the message you forward.

## Include what the handoff needs

- **Assignment.** State the outcome and the delegated agent's role. Carry over the user's acceptance
  criteria and preserve any choices the user explicitly left open.
- **Inputs.** Identify the relevant materials, locations, and current state. Resolve references such
  as “the last report” so the recipient can find the same material. A path is useful only if the
  delegated process can access it. Share the relevant context with that provider only when
  authorized.
- **Constraints.** Pass through the user's requirements, applicable local instructions, and the
  actions available to the delegated agent. Include a stopping point for a decision or approval
  when the assignment already calls for one.
- **Return.** Specify the requested result and where it should go if that is relevant. Include
  evidence, a format, checks, or a blocker report when needed for the requested handoff.

Plain text is enough for many briefs. In a longer brief, headings can distinguish instructions from
source material. Use a file if the CLI expects one or if you need a copy for follow-up. Keep briefs
and logs out of deliverable directories when they would otherwise be mistaken for outputs.

## Optional template

```text
Assignment: <what to do and the intended outcome>
Inputs: <where to find the relevant material and what the agent needs to know>
Constraints: <requirements and available actions that affect the work>
Return: <the result, its destination if applicable, and evidence needed for the handoff>
```

For example, a response-only second opinion can be a single paragraph.

> Read both versions of the notice in the supplied text. Identify any difference in who can appeal,
> the deadline, or what an appeal must include. In your reply, quote the wording behind each finding.

## Multiple agents and follow-up

Keep related outputs together when they need shared context. Split work when each assignment can be
understood and used independently. For a genuinely independent opinion, give each agent the relevant
original materials and evaluation criteria. Share other agents' conclusions when the task is to
reconcile or critique them.

On resume, specify what changed, what should carry forward, and which prior output or decision the
update refers to. If a new session is necessary, include the context the old session would have supplied.
